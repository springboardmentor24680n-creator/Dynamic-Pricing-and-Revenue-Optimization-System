# 🚀 PricePilot AI – Dynamic Pricing Optimization & Revenue Intelligence System

## 📖 About the Project

PricePilot AI is an AI-powered Dynamic Pricing Optimization and Revenue Intelligence System that helps businesses make intelligent pricing decisions using data-driven insights. The platform analyzes historical sales, market trends, competitor pricing, customer demand, and inventory information to recommend optimal product prices that maximize revenue and profitability.

The system combines Artificial Intelligence, Machine Learning, Business Intelligence, and Data Analytics to support dynamic pricing strategies through an interactive web platform. It enables organizations to monitor pricing performance, forecast demand, analyze competitors, and improve overall pricing efficiency.

---

# 🎯 Objectives

- Develop an intelligent pricing optimization platform powered by AI and Machine Learning.
- Predict optimal product prices using historical and real-time business data.
- Forecast product demand to support inventory and pricing decisions.
- Analyze competitor pricing to improve market competitiveness.
- Optimize revenue and profitability through intelligent pricing recommendations.
- Provide interactive dashboards for pricing analytics and business insights.
- Enable secure role-based access for different business users.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/mrunalshisode/AI-Dynamic-Pricing-Optimization-Revenue-Intelligence-System.git
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

Backend Server:

```
http://127.0.0.1:8000
```

Swagger API Documentation:

```
http://127.0.0.1:8000/docs
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend:

```
http://localhost:5173
```
